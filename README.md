# Blinkit_Sales_Analysis

The Blinkit Sales Analysis project presents a comprehensive Power BI dashboard built from a dataset of 8,523 records and 12 columns, focusing on key metrics like Total Sales, Average Sales, Number of Items Sold, and Average Rating. The analysis explores sales performance across product types, fat content, outlet sizes, locations, and types using various visualizations including donut charts, bar charts, line graphs, and matrix cards. Key insights reveal that Fruits, Snacks, and Household items are top performers, while Seafood and Breakfast underperform. Tier 3 cities and medium-sized outlets lead in revenue, with Supermarket Type 1 generating the highest sales. Recommendations include optimizing stock for high-demand items, promoting weaker categories, targeting Tier 3 cities for expansion, and improving customer experience to raise the average rating from 3.9.
